# 🔫 Mamang Gun'Shop Dashboard

Proyek ini adalah aplikasi berbasis **Laravel 12** dengan **Tailwind CSS v4** yang digunakan untuk menampilkan data statis seperti dashboard, profil pengguna, daftar pembeli, dan halaman logout.  
Proyek ini mengimplementasikan *looping data dummy* untuk menampilkan tabel pengelolaan serta penerapan background image berkualitas tinggi pada tampilan.

---

## 🚀 Fitur Utama

- **Halaman Dashboard**: Menampilkan statistik senjata yang dijual dan informasi penting lain.
- **Halaman Pengelolaan**: Menampilkan daftar pembeli senjata dalam bentuk tabel statis (menggunakan array dummy dari controller).
- **Halaman Profil**: Menampilkan informasi pengguna (username, email, password) yang diambil dari login.
- **Halaman Logout**: Menampilkan konfirmasi keluar dengan gaya sederhana.
- **Integrasi Tailwind CSS v4**: Untuk styling cepat, responsif, dan modern.
- **Background Image HD Blur**: Tampilan estetis dengan gambar tidak pecah dan diatur agar selalu proporsional.

---

## ⚙️ Teknologi yang Digunakan

- **Laravel 12**
- **PHP 8.2+**
- **Tailwind CSS 4**
- **Vite (Bundler bawaan Laravel 12)**
- **Blade Template Engine**
